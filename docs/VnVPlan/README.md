# Verification and Validation Plan

[VnVPlan.tex](VnVPlan.tex) defines the planned system tests, review responsibilities, requirement and hazard coverage, and team learning plans. Detailed unit tests remain planned until the MIS defines module interfaces.

Build from the repository root:

```sh
make docs/VnVPlan/VnVPlan.pdf
```

The plan follows the VnV Plan–Main, LO_Plan and LO_Reflect rubrics retrieved through Brightspace MCP for Avenue course 781906 (assignments 364168, 364169 and 364170). It does not report completed test results.

Before submission, the team should confirm the proposed responsibilities and individual learning plans. SRS/HA acceptance conflicts remain tracked in issues [38–43](https://github.com/tandemkv/Tandem/issues?q=is%3Aissue+is%3Aopen+%22Peer+Review%22); the plan records owners and closure evidence. Peer-review issues for the assigned team and full-team TA participation require separate evidence.
